Comece pelo modelo do SketchUp

  1. No SketchUp Pro: Arquivo → Exportar → Modelo 3D…
  2. Em “Tipo”, escolha COLLADA (*.dae) e salve.
  3. Arraste o arquivo .dae (e a pasta de texturas, se houver) para esta tela.

Também aceita .glb, .gltf e .obj. Os componentes bloqueados pelo plugin podem ser exportados normalmente.
